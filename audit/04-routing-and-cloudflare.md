# 04 Routing and Cloudflare

## Rewrite table

Cloudflare Pages `_redirects` defines the clean URL layer:

| Rule | Target | Purpose |
|---|---|---|
| `/quiz` and `/quiz/` | `/quiz.html` | Clean quiz route. |
| `/field-manual` and `/field-manual/` | `/field-manual.html` | Clean Field Manual route. |
| `/base/:slugA/vs/:slugB` | `/compare.html` | Clean comparison result route. |
| `/base/:slug` | `/base.html` | Clean base detail route under `/base`. |
| `/:slug` | `/base.html` | Root-level clean base detail route. |

Ordering is critical: standalone product pages and comparison routes appear before dynamic base rewrites. The catch-all root slug rule must remain last or it can swallow product routes.

## Slug helper responsibilities

`js/slug.js` centralizes:

* preferred slug resolution;
* legacy slug aliases;
* reserved route detection;
* base URL generation;
* compare URL generation;
* parsing clean compare routes;
* parsing clean base routes;
* resolving a base from slug/alias/name.

## Supported route styles

V1 supports both query and clean URL styles for backward compatibility and deployment flexibility:

* base query route: `/base.html?slug=cheyenne-mountain-complex`;
* base clean routes: `/base/cheyenne-mountain-complex` and `/cheyenne-mountain-complex`;
* compare query route: `/compare.html?a=cheyenne-mountain-complex&b=andaman-islands`;
* compare clean route: `/base/cheyenne-mountain-complex/vs/andaman-islands`.

## Hidden assumptions

* The hosting layer supports Cloudflare Pages rewrite syntax.
* Product routes are known and reserved so root-level base slugs do not collide.
* A base slug will not equal `quiz`, `compare`, `rankings`, `field-manual`, `scenarios`, `data`, `js`, `css`, `images` or other static asset paths.
* Generated sitemap URLs and canonical URLs should agree with the routing helper.

## Clean-page duplicates

`quiz/index.html` and `field-manual/index.html` exist as clean-page filesystem duplicates generated by `scripts/generate-clean-pages.py`. These support hosts or crawlers that request directory-style clean paths outside Cloudflare rewrite handling.
